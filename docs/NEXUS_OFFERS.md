# Live Nexus alliance offers

21 September 2026. Ordinary Nexus negotiations now show the owner's named
outgoing offer and let an unallied sender withdraw it. This connects an existing
engine action that previously had controls only in the introduction.

Choose a partner to propose or reciprocate an invitation. Until both agree,
each player remains unallied. The sender may replace the offer or use **Withdraw
your alliance offer**. Withdrawal clears only that player's outgoing offer;
another player's invitation can remain. Existing partners still use **Break
alliance**, which ends their alliance during the Nexus.

The public chronicle distinguishes proposals, withdrawals, formation and breaks.
The player view already exposes ordinary alliance offers; no additional private
information is disclosed. Existing Nexus timing, Homeworld restrictions, Nexus
card forfeiture, readiness reset and authoritative version handling are unchanged.
The underlying [ordinary quote](../game/nexus-alliance.ts) retains the settled
base [rulebook](https://www.gf9games.com/dunegame/wp-content/uploads/Dune-Rulebook.pdf)
contract; this is a control and feedback change, not a new alliance ruling.

A saved unanswered offer remains withdrawable after refresh. If acceptance and
withdrawal race, only one action can commit at that version. A stale withdrawal
is rejected rather than breaking an alliance that formed in the meantime; the
updated table provides the current choices. Unsaved partner selection is only
a local draft. Pending Truthtrance and other response/decision controls preserve
their existing locks.
