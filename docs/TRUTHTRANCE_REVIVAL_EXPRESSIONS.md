positive expression true. No stays live through the actual opportunity deadline:
Basic phase close, or the stamped Advanced participant's close.

progress, records immutable actual returns and lazily generates signed native
constraints. No invalid leaf can hide under a decisive branch. The existing
shipment software bounds of16 leaves/depth4 apply; these are input limits, not

shared force/leader planner. It stores the expression and observed progress,

guide does not force one OR route or one reason for keeping an AND false.

and owned preparation remain. No future foreign choice or unknown resource is

ledger. Actual and detached quote paths use the same typed accounting. Own
spending, requests, Ghola disposal of a needed native return, or Finish cannot
erase every legal completion. Rejected choices leave the original state intact.
