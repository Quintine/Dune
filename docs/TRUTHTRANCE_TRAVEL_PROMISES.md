## One whole answer and native feasibility

Current facts freeze at the actual answer. Unknown is false for a definite Yes
and true for No, retaining the earlier guaranteed-aggregate interpretation.
Unknown-fact correlations are not inferred. No negates the whole tree, not each
leaf. A true current fact OR action, or false current fact AND action, can make
the selected answer terminal without a future commitment.

`game/travel-expression-promises.ts` lazily reduces the whole compiled answer
to signed branches, folding actual progress and closed opportunities. Every
shipment leaf shares one event. Native min/cap contradictions are pruned;
alternatives remain available rather than binding one route. Private detached
witnesses translate a branch into existing shipment and movement constraints,
then call the original ground-movement completion search. The real ledgers never
receive that selected branch. Quotes retain original force types, wallets,
movement allowance, routes, owned card preparation and prior native promises.

Actual shipment/ground hooks record receipts; a qualifying whole Yes fulfills
immediately. Whole No remains binding through the respondent's actual turn end.
Ending cannot erase a required action. Spending or consuming the last owned
route is rejected. An opposing completed effect can release a now-impossible
answer; interrupted responses retain original priority.

At the first combined answer, the private order records existing shipment rows
and the native within-movement sequence before the new row. Subsequent real
scalar, whole/mixed movement, shipment and travel answers append their native
ledger index. Joint feasibility reconciles prefixes in that accepted order;
no virtual branch is made permanent. Historical ordering between different
native families before this cutover is not reconstructed. Wider cross-family
