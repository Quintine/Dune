## Source and behavior

[Source contract](ECAZ_VICTORY_RULES.md) records GF9 E3 pp.8,15–16 and applicable base/E1/E2 rules. Both Ecaz and its current reciprocal ally must have effective non-advisor presence in each of three distinct uncontested strongholds. Their ordinary four-stronghold union remains available. One faction holding all three Tech Tokens supplies one ordinary stronghold equivalent; split ownership does not, and tokens never supply a jointly occupied territory. A concealed No-Field supplies public presence without revealing its denomination. Only a placed Hidden Mobile Stronghold counts. Existing storm/control, advisor release and private BG prediction precedence are retained.

`game/victory-progress.ts` is the shared pure public calculation. It returns ordered member IDs, uncontested stronghold IDs, the ordinary threshold, complete-set bonus, jointly occupied IDs, the Ecaz threshold and prospective eligibility. It validates the entire faction/alliance roster, public board, advisor shapes/locations and token ownership. It reads no predictions, hands, traitors, resources, concealed token inventories or token spice. Arrays are detached.

`game/victory-quote.ts` uses these qualifiers before the existing private BG interception and distinct final-turn fallbacks. The existing commit path awards the result once and settles final Stronghold Cards from the same board. An actual Ecaz joint win adds a chronicle explanation naming its strongholds. A BG replacement win does not falsely receive the Ecaz explanation.

`viewGame` projects public progress from the original board, before local advisor normalization; malformed public state produces no unreliable preview while authoritative victory rejects it. `components/victory-progress.tsx` displays one row per side, separates ordinary and joint counts, and explicitly describes a prospective board calculation. It awards no early win. Its native disclosure supports keyboard controls and responsive layout. The internal victory and faction/movement guides describe the supported boundary.

AI destination threats, Trip to Gamont target assessment and Guild timing now consume the same public progress. Hard/Brutal additionally value joining their Ecaz ally in an incompletely shared stronghold. These scores grant no movement permission or hidden information; legal entry and shipment controls still apply. This is a verified policy behavior, not an AI strength calibration claim.
