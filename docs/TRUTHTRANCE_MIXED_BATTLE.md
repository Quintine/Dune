# Truthtrance current facts and current battle plans

## Mixed aggregate prototype — 26 October 2026

**Prototyped / Partial.** The packet is
`{kind:'mixedBattlePlan',target,battle,territory,mixed}`. Generic fact/action/AND/OR
clauses use scalar native PlanClaim leaves: dial, support, weapon, defense,
leader/hero and Kwisatz. No action embeds its own group. All groups share one
raw logical budget. The current battle/territory and another actual combatant
are mandatory; original pure questions and game-start gates remain unchanged.

supplied Advanced physical39/printed37 compliance/release/unknown and existing

correlated unknown inference or complete current-turn action language is claimed.

All current facts freeze at the actual answer, before future payments,
preparations and card changes. A real later bribe can change spice without
changing the original fact. No negates the entire mixed expression. Unknown
uses false for definite Yes and true for No, then the native plan obligation
must guarantee the aggregate. If neither guaranteed completion is known,
unknown/save/change-question remains available.

True fact OR plan can settle Yes immediately; false fact AND plan No immediately.
Constants need no native binding. Otherwise the remaining tree enters the
existing BattlePromise ledger. Native numeric/half-dial, support, empty slots,
card names, leader/Cheap Hero and Kwisatz conditions retain original meanings.
The claim concerns selected plans, not whether a weapon effect later succeeds.

The original pure question allows an already submitted or revealed respondent.
Those choices are fixed; mixed answers against them are terminal immediately
and add no new residual. A newly binding open aggregate stays pending during
solver/preparation/Fill previews and after only its own seal. It fulfills at
the sole actual native global plan reveal, before counterdecisions or synchronous
battle cleanup. Later native residual release or an ended/replaced unrevealed
source releases the pending aggregate. Facts are never reevaluated at reveal.

through `parsePlanClaim`; it cannot hide an action group or source metadata.
`game/mixed-action-question.ts` adds optional maxNodes/maxTerms and one shared
logical size helper. The full raw battle tree counts16 clauses including all
outer and nested fact groups,8 children per group and depth4. Fact wrappers count
their actual logical subtree once. Other mixed families retain their original
16-leaf/depth4 limits and broader group arity when no new cap is selected.
These are software input limits, not extra printed game restrictions.

Every fact is snapshotted before compiler folding. Only an action residual
uses native `battleTruthAnswers`/`bindBattleTruth`, `findReachableBattlePlan` and
`validatePlan`. Voice, ordinary/full Prescience, inspections, actual owned card/
Ghola/Karama/income preparation, prior promises and financial rules stay there.
No second battle or payment solver is added. A new optional BattlePromise event
links only mixed residuals; old pure record shapes stay.

Raw `mixedBattleQuestions` retains the original question, public battle source,
answer and terminal status. Every viewer's public battle.truthPromises filters
mixed event IDs, even after reveal; native completion and authoritative plan
validation retain the full private ledger. Own mixed projection exposes raw
question/aggregate flags without binding metadata, compiled claims or frozen
fact answers. Persistent status survives battle cleanup. Minimal bots prioritize
the existing private compliant fallback for a live mixed question; they never
reconstruct hidden clauses or gain strategic/private information.

New native battles already have a public UUID. Older eventless current battles
accept a null source only while that exact source is still missing; a successful
explicit Ask atomically assigns one identity and stores the canonical question.
Passive projection does not initialize it. Failed actions remain detached; no
clock, purse, card, force, plan or existing answer is reset or converted.
New mixed discard signatures include raw metadata and the already signed native
battle/residual; old capture branches/signatures remain unchanged.

facts and repairable native scalar drafts with unique IDs. Public leader/card
choices do not inspect private hands or affordability. Raw preview/Ask and
respondent-only answer choices connect through Truthtrance and the table.

The own aggregate panel is status-only. Existing BattlePromises supplies one
native private preparation/Fill surface, including mixed-only immediate plans.
Fill changes a reviewable draft and never seals automatically. Mixed callbacks
retain actor/turn/battle/participants/raw-question/guide identity and quiet/busy/
room guards without reading residuals. Already sealed/revealed/terminal mixed
contexts offer no Fill. Ordinary private preparation without any Truthtrance
records keeps its existing behavior. Other legal native plans remain available.
