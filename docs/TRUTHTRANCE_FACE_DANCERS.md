# Truthtrance: current unrevealed Face Dancer identities

## Source and predicate — 24 October 2026

**Prototyped / Partial.** The [publisher November2020 FAQ, printed p8](https://www.gf9games.com/dune/wp-content/uploads/2020/11/Dune-FAQ-Nov-2020.pdf)
allows game-related Yes/No questions and AND/OR combinations. The
[publisher E1 rules, printed p6](https://www.gf9games.com/dunegame/wp-content/uploads/2020/09/IxianAndTleilaxuRulebook.pdf)
establish native Tleilaxu's three Face Dancer cards separately from ordinary
Traitors. The authorized supplied Advanced revision, physical **p38 A** and
**p39 Truthtrance**, retains those cards and broad question permission.
Official indexed text was retrieved; direct FAQ access returned403. This is a
composition of those permissions and a precisely worded current fact, not a
new Face-Dancer-specific publisher FAQ or a new faction power.

The structured fact asks whether the respondent **currently holds the named
identity as an unrevealed Face Dancer**. One matching current card with
`revealed === false` answers Yes. Revealed, absent or returned cards answer No;
history and ordinary Traitor cards do not count. An absent undealt card is not
a prediction of the upcoming deal. Ordinary selected-Traitor questions keep
their existing meaning, including their original selection-time uncertainty.

The identity comes from public native printed rosters plus the shared Cheap
Hero/Heroine Traitor identity; shared Duke has no such card and stays invalid.
The selector never uses the respondent's private cards to populate candidates.
Leader life, captivity, Ghola control or fighting strength does not change this
identity predicate. Auditor is valid when its actual printed identity is in
the selected game; no card, module or roster is invented by asking a question.

## Connected behavior

The focused helper owns exact shape/identity parsing, current matching and
question wording. Shared Truthtrance parsing/evaluation/text uses it, including
existing nested AND/OR questions. The existing target-only verified answer,
storm-order priority, physical question-card disposal and parent continuation
remain. Only the question and whole answer become public; no underlying list
or per-clause match is added to other views. Shared mixed-shipment fact fields
also recognize the predicate, while existing mixed-question mode/turn gates
remain. Native Tleilaxu's current expansion profile does not gain a mixed-shipment
entry merely because this fact exists.

Persistent author controls explicitly distinguish currently unrevealed Face
Dancers from ordinary Traitors and future promises. A current Yes does not
reveal a physical Face Dancer, make it turn traitor, commit a later Face Dance,
or require retaining the card. Actual later native Mentat replacement is still
legal; the historical answer remains about the earlier current holdings.
All four profiles use the same existing owner-only verified-answer path;
there is no new question strategy or calibration.

## Native source and bounded proof

The fixture uses public Basic or explicit Advanced-preview Tleilaxu/Atreides/
Emperor setup with the original Ix family. Atreides is dealt its original
Truthtrance, other players choose actual Traitors, and native setup deals
Tleilaxu three actual Face Dancers. Native Storm/Spice reaches clean Charity.
Only original undealt card/Spice positions and scalar shuffle choices are
selected; no played hand, Face Dancer status, phase, wallet, answer or receipt
is assigned. Optional branches actually reach first Mentat and replace one
unrevealed Face Dancer before or after the answer. Basic and Advanced initial
sources take26/29 actions; replacement-first sources take60/63.

The frozen **12-file86/86** affected offline union, `npm run check:quick`,
production build and changed-control runtime smoke pass. Nine focused helper,
thirteen actual engine and six control cases cover held/unheld/revealed/returned
identity, exact parsing, Hero/Auditor/Duke boundaries, ordinary Traitor separation,
compound aggregate, rejected answers, original physical disposal and actual
Mentat replacement. The existing Truthtrance/knowledge/hand/count/No-Field/mixed
and shared-Duke file union retains its own bounded behavior.

Twelve actual identity-field callback/question/answer/full GameTable SSR
journeys cover Basic and Advanced held/unheld, OR aggregates, replacement-first
old/new and answer-then-replace. Their original parents resume; histories remain
correct after custody changes. Sixteen own-view answer paths across all four
existing profiles accept sixteen native Yes/No actions. Runtime source is
genuine native play; this is not browser/hydration/mobile or complete-game proof.
